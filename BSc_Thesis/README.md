# Muhafiz e Wattan

**Muhafiz e Wattan** is a bachelor’s final-year project developed at COMSATS University Islamabad, Wah Campus (2016–2020). It is a 3D first-person shooter designed around a virtual counter-terrorism training scenario.

## Project overview

The player navigates a 3D environment, completes target practice, and faces computer-controlled opponents. The project explores how an interactive game environment could be used to practise targeting and decision-making.

The game design includes:

- A target-practice level with 12 targets
- Single-player levels with computer-controlled enemies
- A multiplayer level
- Player movement, jumping, crouching, weapons, ammunition, and health
- Level selection and pause menus

## Tools

- Unity 3D
- Blender for some 3D models
- Windows 10 development environment
