### 🌐 KnowledgeGraphProject
A Knowledge Graph and data engineering project based on football player and market-value data from Transfermarkt.  
The project includes ontology modeling, OWL/RDF, Python-based data cleaning and serialization, GraphDB, SPARQL queries, and data analysis.  
It demonstrates practical experience with Semantic Web technologies, graph data modeling, data engineering, and visualization.

### 🩺 Medical-Chatbot
An AI-powered Medical Document Assistant that allows users to upload PDF documents and ask questions about their content.  
It uses FastAPI, Streamlit, LangChain, Pinecone, HuggingFace embeddings, Groq LLMs, PostgreSQL, JWT authentication, and Retrieval-Augmented Generation (RAG).  
The system supports hybrid search, reranking, conversation memory, document summaries, citations, multiple chat sessions, and an evaluation dashboard.

### 🎓 MyThesis
This folder contains my MSc thesis completed in Computer Engineering at the University of Padua.  
My research focused on Knowledge Graph Embeddings for Link Prediction and evaluated models including TransE, ComplEx-N3, TuckER, CrossE, SimplE, and TorusE.  
The repository contains thesis material, experimental results, model comparisons, and related research outputs.
