# Clinic Booking System

A full-stack clinic booking application built with React, Express, and a database-backed backend for managing patient appointments efficiently.

## Project Summary

- Built a clinic booking system that supports appointment scheduling with patient details, service selection, doctor choice, and time-slot validation.
- Developed a responsive web interface and backend routes to create, search, and update appointments for a practical healthcare workflow.
- Designed the project as a strong full-stack prototype demonstrating front-end development, API integration, and database-driven application logic.

## Features

- Create new patient appointments
- Select service, doctor, date, and time
- Disable already booked doctor time slots
- Search daily appointments, by name, or by date
- Toggle appointments between pending and confirmed
- Responsive layout for desktop and mobile
- Receive appointment confirmation through Email

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Then open the local URL shown by Vite.

## Notes

This project demonstrates a complete booking workflow and can be extended with authentication, patient records, notifications, and payment or insurance features in a production version.
