Invoice AI (Backend)

Invoice AI is a multi-tenant SaaS backend designed to process invoices securely using AI.
This repository contains the backend service built with FastAPI, PostgreSQL, and Docker, focusing on tenant isolation, role-based access control, and scalable architecture.

Roadmap (Planned)

    Invoice upload (PDF / images)

    OCR & extraction pipeline

    AI-powered invoice analysis

    Token usage tracking

    Multi-provider AI routing

    Google OAuth authentication

    Stripe billing

    Reporting & exports

Learning Goals of This Project

    Real-world SaaS backend design
